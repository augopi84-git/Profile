## 🚀 Local Development

### Prerequisites
* **Rust**: `1.80+` (`cargo` and `rustc`)
* **Node.js**: `v18+` or `v20+` (`npm`)

### 1. Run the Rust Profile Engine
```bash
# Validates data, runs algorithmic simulations & generates public/profile_metrics.json
cargo run --manifest-path crates/profile-engine/Cargo.toml -- all
```

### 2. Start Web Development Server
```bash
# Install dependencies
npm install

# Start Vite live reload server at http://localhost:3000
npm run dev
```

### 3. Render Remotion Video Reel to MP4
```bash
# Renders out/gopinath-profile-reel.mp4 using Remotion CLI
npm run render:video
```

## 🌐 Deploying to GitHub Pages (`https://github.com/augopi84-git`)

This repository is pre-configured with a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds both the **Rust Engine** and the **React/Remotion static site**, then publishes it directly to **GitHub Pages**.

### Step 1: Create a GitHub Repository
On your GitHub account ([augopi84-git](https://github.com/augopi84-git)), create a new repository:
* If you name it `Profile`, the site will be at: **`https://augopi84-git.github.io/Profile/`**
* If you name it `augopi84-git.github.io`, the site will be at your root domain: **`https://augopi84-git.github.io/`**

### Step 2: Push Your Local Code to GitHub
In your local terminal:
```bash
git add .
git commit -m "feat: complete executive profile website utilizing Remotion and Rust"
git remote add origin https://github.com/augopi84-git/Profile.git
git push -u origin main
```
*(If your repository is named `augopi84-git.github.io`, replace `Profile.git` with `augopi84-git.github.io.git`)*

### Step 3: Enable GitHub Pages via GitHub Actions
1. Open your repository on GitHub: `https://github.com/augopi84-git/Profile/settings/pages`
2. Under **Build and deployment** > **Source**, select:
   **`GitHub Actions`**
3. Push any commit or click **Run workflow** under the **Actions** tab.
4. Your website will be live in ~2 minutes!
